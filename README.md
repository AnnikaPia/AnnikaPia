# UP Element Library Analysis

## Overview
This project investigates how synthetic 19 bp UP element sequences influence promoter strength in bacteria.

## Approach
- Generated a library of synthetic 19 bp sequences
- Measured promoter activity using sort-seq
- Built a feature-based model to relate sequence composition to expression levels

## Key Idea
UP elements enhance transcription by interacting with RNA polymerase.  
This project aims to identify sequence features that contribute most to promoter strength.

## Methods
- High-throughput sequencing (sort-seq)
- Sequence feature extraction
- Statistical / computational modeling

## Outcome
The model links specific sequence features to promoter activity, helping to better understand transcriptional regulation.
